# Alisha Tamboli Portfolio

A modern portfolio website built with React, Vite, and GSAP animations.

## Tech Stack

- React 18
- Vite
- GSAP
- Radix UI components
- React Helmet Async

## Getting Started

### 1. Install dependencies

```bash
npm install
```
### 2. Start development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

The production build is generated in the `build/` directory.

## Project Structure

- `src/` - Application source code
- `public/` - Static assets
- `build/` - Production output
- `index.html` - App entry HTML
- `vite.config.ts` - Vite configuration

## Deployment

This project includes a `netlify.toml` file for Netlify deployment.
